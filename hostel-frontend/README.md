# Hostel Management – Frontend

## About

The frontend for the Hostel Management – Verified Reviews and Ratings application. It allows students to browse hostel listings, log in, and view hostel reviews and ratings.

## Features

* Student login and registration
* Hostel listings
* Review and rating display
* Frontend integration with the backend API

## Technologies Used

* React
* JavaScript
* Vite
* Axios
* React Router

## Requirements

* Node.js
* npm
* Hostel Management backend

## Installation

Install the project dependencies:

```bash
npm install
```

## Run the Application

Start the development server:

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

## Backend Connection

The frontend communicates with the Spring Boot backend running locally at `http://localhost:8080`.

## Project Status

This project is under development. The homepage, hostel listings, login, and review display have been tested. Review authorization is still being investigated.

## Note

This is a student learning project and is not yet prepared for production deployment.
